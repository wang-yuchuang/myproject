# docs/ SVG 图表风格指南

本指南约束 docs/ 目录下所有手写 SVG 图表的写法。目标：风格统一、离线可渲染、无障碍可读、结论可溯源。

## 1. 适用范围与原则

- docs/ 下的图表一律手写 SVG，不使用 drawio 或其他外部绘图工具。
- 图优先，md 只做读图指引。图自身要能独立传达完整信息。
- 每图自带 `<title>` 与 `<desc>`，服务无障碍阅读与全文检索。
- 必须离线可渲染：不引用外部字体、图片、CSS、脚本，一切资源内联。

## 2. 根元素模板

每个 SVG 文件的根元素按以下模板书写：

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1160 H" role="img" aria-labelledby="ttl desc" style="max-width:1160px;width:100%;height:auto;background:#fff">
  <title id="ttl">…</title>
  <desc id="desc">…</desc>
</svg>
```

说明：

- 画布宽度 W 固定为 1160，高度 H 按内容调整。
- 禁止带 px 单位的 width/height 属性，缩放交给 viewBox 与 style 处理。
- 禁止 `<!DOCTYPE>` 声明。

## 3. 字体

每个 `<text>` 元素必须携带完整的 font-family 值：

```text
font-family="'Noto Sans CJK SC','Source Han Sans SC','PingFang SC','Microsoft YaHei','Droid Sans Fallback',sans-serif"
```

字号表：

| 用途 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 图标题 | 22 | 700 | #202124 |
| 副标题与注释 | 13 | 400 | #5F6368 |
| 泳道头 | 14 | 600 | #202124 |
| 节点标题 | 14 | 600 | #202124 |
| 节点正文 | 12 | 400 | #5F6368 |
| 来源标签 | 10.5 | 400 | #80868B |
| 图例 | 12 | 400 | #202124 |

## 4. 语义配色表

fill 与 stroke 成对使用，语义固定，不得挪作他用：

| 语义 | fill | stroke |
|------|------|--------|
| BSP 系统侧 | #E8F0FE | #1A73E8 |
| SDK 挂载侧 | #FEF7E0 | #F9AB00 |
| 应用分区/脚本 | #E6F4EA | #137333 |
| 业务进程/模块 | #F3E8FD | #8430CE |
| 失效/断链/真空 | #FCE8E6 | #C5221F |
| 外部/存储 | #F1F3F4 | #5F6368 |
| 中性框/泳道 | #F8F9FA | #DADCE0 |

文字三档：主文字 #202124，次要文字 #5F6368，淡色注记 #80868B。画布底色 #FFFFFF。

描边宽度三档：普通节点 1.5，强调元素 2，泳道边框 1.2。

## 5. 节点几何约定

| 节点类型 | 几何写法 |
|----------|----------|
| 进程/可执行 | `rect rx=10` |
| shell 脚本 | `rect rx=3`，左侧加 4px 宽的强调条 |
| .so 库 | `rect rx=18`（胶囊形） |
| 决策 | `polygon` 菱形 |
| 数据存储（DB/文件） | 带椭圆顶的 `path` 圆柱 |
| 外部系统 | `rect rx=10` 加 `stroke-dasharray="6 3"` |
| 阶段带 | `rect rx=8` 加 `opacity=0.45` |

## 6. 文字排版硬约束

- 中文字符宽按 1.0×字号估算，拉丁字符按 0.55×字号估算。
- 节点内宽必须 ≥ 该行宽度估算值加 24（左右各留约 12px 余量）。
- 主列节点宽度取 140~300。
- 每行最多 16 个中文字，超长内容换行，拆成多个 `<text>`。
- 禁止文字溢出矩形。实在放不下就缩短文字，完整名称写进 `<desc>`。

## 7. 箭头与连线

在 `<defs>` 中统一定义两个箭头 marker：

- `marker id="arw"`：灰色 #5F6368，正常流使用。
- `marker id="arw-broken"`：红色 #C5221F，断链/失效流使用。

线型规则：

| 流类型 | stroke | width | dasharray |
|--------|--------|-------|-----------|
| 正常流 | #5F6368 | 1.6 | 无 |
| 断链/失效流 | #C5221F | 1.6 | `7 4` |

线上标签统一 11px。

## 8. 布局

- 层级之间的间距至少 40px。
- 元素按网格对齐，坐标取整数。
- 避免箭头交叉，宁可多绕一层布局。
- 图底部：左侧放图例，右侧放来源注记。
- 每个事实节点必须带 `file:line` 形式的淡色来源标签（10.5px，#80868B），标明结论出处。

## 9. 文件与命名

- 存放路径：`docs/<section>/svg/<prefix>-<NN>-<slug>.svg`
- 命名示例：`docs/10-architecture/svg/boot-01-power-on-chain.svg`
  - `prefix` 为主题前缀，`NN` 为两位序号，`slug` 为小写短横线描述。
- md 中引用：`![说明](svg/xxx.svg)`，相对路径指向同目录下的 svg/ 子目录。
- 与图同名的 md 负责读图指引与内容扩展，不重复图中已有的整句文字。
