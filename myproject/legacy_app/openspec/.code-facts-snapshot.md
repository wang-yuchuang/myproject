### 运行时可写路径与 DB/锁文件（2026-09-16 真机取证）

> **挂载拓扑（2026-09-16 复核修正）**：`/data` 挂载 `/dev/mmcblk0p45`（`S00data_mount` 的 `USERDATA_POINT="/data"`）；`/opt/appdata` **不是 `/data` 下的普通目录，而是一次 bind mount** —— `S00data_mount` 的 `BIND_MOUNTS` 含 `opt/appdata|/opt/appdata`，源为 `${USERDATA_POINT}/rootfs/opt/appdata` = **`/data/rootfs/opt/appdata`**（真机已核实其内含 `.app_rollback_state`、`config/`、`data/`、`log/`）。故二者**同分区、不同目录**（`/data/rootfs/` 的兄弟关系），`/proc/mounts` 中两者均显示为 `/dev/mmcblk0p45`。
>
> ⚠️ **方法教训**：`readlink -f` **检测不出 bind mount**（2026-09-16 曾据此误判为“两个无关目录”，并被 `df` 的同设备同占用误导）；判定 bind 应看 **`/proc/mounts` / `findmnt` / `mountpoint -q`**。

| 路径 | 内容 |
|---|---|
| `/opt/appdata/log/trace.log` | 应用 stdout/stderr（fd 1,2）与 `iLog4c` 追踪日志 |
| `/opt/appdata/data/`（＝ `/data/rootfs/opt/appdata/data/`） | `syshand.pid`、`nccu.pid`、`syshand.run`、`nccu_web.ipc.PP/RR`、`.syscmd_locker`、`.logIdx` |
| `/opt/appdata/data/.{applog,bmsrundata,clouddata}.lock` | 三个 DB 的**锁文件**（`iDataBase.c:34/39/44`） |
| **`/data/` 顶层**（**非** `/opt/appdata` 下） | **`AppLog.data`、`BmsRunData.data`、`CloudData.data`、`nccu.data`** —— 四个 **SQLite 数据库**文件；另有 `loginfo.N` |
| `/opt/appdata/data/{upgradefile,app_nccu.tar.gz,pkg.sum,firm_tmp_extract/,keepalived_*,ext_rtinfo}` | 升级临时件与路由/主备配置（约 120 处代码引用，**均非 DB**） |

⚠️ **`AppLog.data` 是 SQLite 数据库文件，不是文本日志** —— 对其使用 `grep -c <字符串>` 得到的是二进制页里的偶然匹配，**不能当作事件计数**（2026-09-16 曾据此误判，特此记录）。

**DB 路径的决定性依据（4 条独立证据，2026-09-16）**：

1. `iDataBase.c` **全部 6 处** DB 路径构造均用 `getenv("NCCU_DATA_PATH")`：`:66`（BmsRunData）、`:220`、`:687`、`:890`、`:955`、`:1024`、`:1165`
2. `iDataBase.c:691` 环境变量缺失时**硬编码兜底 `/data`**（原作者注释：`if env not provided, should use default PATH`）
3. **所有平台变体**的启动脚本均设 `NCCU_DATA_PATH="/data"`：`startrun:15` / `mu3/startrun:15` / `run_app:10` / `mu3/run_app:10` / `run_app.debug:18` / `mu3/run_app.debug:18` / `start_ui:9` / `log_cat:7` / `start_web_server:34` / `server_main.conf:142` —— **无一变体**使用 `/opt/appdata/data`
4. 真机 `stat`：`/data/nccu.data` 存在（inode `22`）；`/opt/appdata/data/nccu.data` → **`No such file or directory`**

→ 因此**任何形如 `/opt/appdata/data/<name>.data` 的 DB 路径描述都是错的**（`app-lifecycle` R8 步骤 5 曾如此记载，2026-09-16 修正）。

```c
if(ABS(tmNow - tmLastHeartBeat) >= 10)   // 10s 窗口
```
