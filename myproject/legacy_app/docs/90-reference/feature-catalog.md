legacy_app 是运行在 SemiDrive D9360 平台上的储能后备管理业务程序。它把储能现场的电池、
变流器、电表等设备数据采集上来，在本地完成状态计算与告警判断，再按业务需要送到云平台
或本地界面。

## 功能清单

| 功能 | 说明（对外语言） | 备注 |
|---|---|---|

| 通道异常感知 | 通信通道异常自动转为事件，进入统一告警流程 | |

## 协议与对接

- MQTT：云平台与运维后台主通道。
- Modbus TCP / Modbus RTU：客户平台对接与现场设备采集。
- DLT645：电表采集。
- IEC 101 / 104 / 61850：⚠️ 对应上报模块当前未编译进固件，暂不可用。
- HTTP / FTP：文件与数据传输通道。
- WebSocket：本地 web 与云通道，固件内含两套实现，按配置选用。
- CAN：电池等现场设备接入。
- RPMSG：与协处理器（R 核）的跨核通信。

## 机型与形态

- 平台变体：BMU05 / EMU01 / IMMU3 三种机型，共用同一套业务程序。
- A/B 双分区：应用固件双分区保存，OTA 升级写备用分区，升级失败可回退。
- 只读与可写分离：应用分区只读并做完整性校验，运行数据写入独立数据区，升级不丢数据。

## 不承诺范围

- 不包含 BSP、内核与分区管理，这些由 SDK / 底板支持包提供。
- 不包含云侧平台功能，本程序只负责设备侧的数据采集与上报。
- 应用启动的门控时机由 BSP 侧在途变更决定，以设备实际 BSP 版本为准。
