# legacy_app — Solaris Backup Management System

基于 SemiDrive D9360 平台的储能后备管理系统 App 层业务程序。

## 构建

```bash
./build.sh            # 一键构建（编译 + 签名 + RAUC bundle）
./build.sh build      # 仅编译
./build.sh clean      # 清理
```
